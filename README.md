# 3modeLED_arduinoNano
An arduino nano project that is able to set three mode on LED: on, off, auto. Auto mode is basically the ability of LED to adjust its brightness regarding the light intensity surrounded an LDR (Light Dependent Resistor) sensor.

Requirements:
-	Arduino Nano
-	Breadboard
-	Light Emitting Diode (LED): 2 buah
-	Resistor 220 Ohm: 2 buah
-	Light Dependent Resistor (LDR): 1 buah
-	Resistor 10k Ohm: 1 buah
-	Tactile Switch/Push Button: 1 buah
-	Jumper Wire Male-to-Male:  4 buah
